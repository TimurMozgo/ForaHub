# Dead Route в хабе

Игра запускается внутри полноэкранного окна хаба. Для главы I использована копия исходной сборки `dead-route/dist`, для следующих глав — `dead-route-chapter-two/playable`. Оригинальные папки не изменены.

Новая кампания начинается в первой главе. После пяти районов открывается глава II, затем доступные эпизоды главы III. Общая контрольная точка переносит отряд, здоровье, оружие, патроны, гранаты и деньги между главами. Завершённые главы отмечаются в сохранении. Ранее начатые сохранения второй главы переносятся без сброса; игрок может начать с первой главы, сохранив резервную копию прежней кампании для восстановления.

Сохранение локальное и привязано к вошедшему в хаб пользователю. Серверная копия хранится в D1 через `/api/dead-route/save` с проверкой владельца и ревизий. При споре двух версий игрок выбирает нужную, а прежняя остаётся доступной для восстановления. Перед выходом в хаб и переходом между главами состояние записывается.

Сохраняется контрольная точка на входе в район или перед магазином. Незавершённый бой, положение врагов и промежуточные диалоги после перезапуска проходят заново. Раздел главы III охватывает только эпизоды, присутствующие в предоставленной сборке; дальнейшее продолжение можно добавить позднее.

Проверки: `node scripts/test-dead.mjs` и `node scripts/test-dead-adapter.mjs`.
